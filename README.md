
# Cat Rescue and Adoption System

## Project Description

The Cat Rescue and Adoption System is a C-based Data Structure Lab project.
The main purpose of this project is to manage rescued cats and organize
the adoption process in a simple and efficient way.

## Objectives

- Manage rescued cat information
- Store cat records in an organized way
- Display available cat information
- Manage adoption requests
- Make the adoption process easier and more organized

## Main Features

- Add cat information
- View cat information
- Manage rescued cats
- Submit adoption requests
- Process adoption requests
- Display system information

## Data Structures Used

### Array
Array is used to store and manage cat information.

### Queue
Queue is used to manage adoption requests using the
FIFO (First In, First Out) principle.

## Programming Language

C

## Course

Data Structure Lab

Academic Project
